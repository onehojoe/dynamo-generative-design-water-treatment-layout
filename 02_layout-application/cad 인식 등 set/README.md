# cad 인식 등 set — CAD 도면을 Dynamo 가 읽게 만들기

배치 그래프에 들어가기 전 단계입니다. DWG 를 Dynamo 로 가져와 대지 경계·시설물·출입·범례를
레이어별로 분리해 인식시키고, 그 결과를 Generative Design 스터디로 넘깁니다.

## 파일

| 파일 | 크기 | 내용 |
|---|---:|---|
| `대지경계.dwg` | 27 KB | 대지 경계선 |
| `BOX.dwg` | 28 KB | 시설물 박스 |
| `출입.dwg` | 27 KB | 출입 동선 |
| `범례.dwg` | 30 KB | 범례 |
| `대안 셈플.dwg` | 51 KB | 대안 예시 |
| `240213 정수장 관련 test v1.dyn` | 656 KB | 노드 341. CAD 인식 → 배치 |
| `2500726 정수장 python 최적화 v1.dyn` | 685 KB | 노드 354. Python 노드로 최적화 |
| `배치 Sample 정수장.rvt` | 3.8 MB | 샘플 모델 (Revit 2024) |

## 요구 패키지

두 `.dyn` 모두 아래 패키지가 필요합니다. 없으면 노드가 회색으로 뜹니다.

| 패키지 | 버전 |
|---|---|
| GenerativeDesign | 6.1.1.0 |
| **Dynamo Text** | **2.0.1** |

Dynamo 버전은 **2.19.3.6394** (Revit 2024) 입니다.

## 흔한 함정

- **레이어 이름 규칙이 문서화돼 있지 않은 도면이 대부분입니다.** 이름이 아니라 속성으로 거르는 경로를 항상 함께 만듭니다
- 육안으로 닫혀 보이는 폴리라인이 실제로는 열려 있습니다. 반드시 기계로 검사합니다
- DWG 를 링크로 가져올 때 좌표계와 단위가 어긋나면 이후 전부 틀어집니다. 단위 변환은 마지막이 아니라 처음에 잡습니다
- `Dynamo Text` 가 설치돼 있지 않으면 그래프가 열리기는 하나 실행되지 않습니다
