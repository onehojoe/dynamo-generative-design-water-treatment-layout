## 0. 한 줄 정의

NATM **도로터널의 내공단면(3심원)** 을 설계 조건에서 산정하고, 조건을 스윕해 대안을 비교·판정·선정하는
**브라우저 워크벤치**. Revit/Dynamo 없이 돈다. 산출은 DXF·JSON·CSV·검토보고서.

- 발주/출처 = **한국종합기술 기술연구소** 제공 자료(PPT 60슬라이드 + Dynamo .dyn + 입력 엑셀).
- **Revit 애드인은 범위 밖**(2026-08-25 결정). BIM 연계는 **계약(JSON/DXF)까지**만 한다.

## 1. ★불변식 (INVARIANTS) — 깨면 안 되는 것

### I-1. R1 규칙은 회귀 테스트다

```
O1 = (0, EL1)
R1 = ceil5( max |O1 → (시설한계 ⊕ 시공오차 t)| )
```

이 규칙은 발주처 **원본 결과 60행 중 56행과 정확히 일치**한다(게이트 G2).
"개선"하지 마라. 개선하고 싶으면 **옵션을 추가하고 기본값은 이 규칙으로 두라.**
미일치 4행(`cc=-0.9 · 편경사 +2%`)은 원본이 9~14mm 크게 잡은 것이고 **원인 미확인**이다.
`±s 대칭 가설`(`max(need(+s), need(-s))`)은 이미 시험했고 **44/60 으로 악화되어 반증**됐다. 다시 시도하지 마라.

### I-2. 증거 등급을 섞지 마라

| 항목 | 등급 | 말할 수 있는 것 |
|---|---|---|
| 시설한계 8점 폴리곤 | **원본 이식** | 원본 .dyn Python 노드와 동일. 10800×4800·51.040㎡ 검산 통과 |
| R1 규칙 | **원본과 56/60 일치** | "원본과 일치한다"고 말해도 된다(56/60 이라는 수치와 함께) |
| R2 / R2′ | **신규 정의** | ★"원본을 재현했다"고 **절대 말하면 안 된다.** 원본 산정식은 자료에 없다 |
| 판정 기준(편평률 0.55 · 여유폭 50mm) | **추정 / 잠정** | 확정 기준이 아니다. 항상 이 사실을 붙여 말한다 |
| 부대공 배치 | **가정** | 자료에 배치 기준이 없다 |

### I-3. 라이닝은 연직, 도로만 기운다

편경사 `s` 는 **도로·시설한계·공동구·부대공만** 원점 기준으로 회전시킨다. 라이닝(R1/R2/R2′)은 연직을 유지한다.
편경사는 원본과 동일하게 `s(%)/100` 을 **라디안으로 직결**하는 소각근사를 쓴다(2% → 0.02 rad, 반경 5.4m 에서 편차 0.02mm 미만).
이 근사를 "정확한 atan 으로 고치는" 변경은 원본과의 대조(I-1)를 깨뜨릴 수 있다. 하려면 게이트 G2 를 먼저 돌려라.

### I-4. 라이닝 하단 기준선은 y=0 이 아니라 **노면선**이다

노면선 = 원점을 지나고 방향 `u=(cos s, sin s)` 인 직선.
초기 구현은 `y=0` 수평선으로 잡았다가 **편경사가 붙는 순간 시설한계 하단을 잘라먹었다**(900/900 조합 위반, 게이트 G3 가 검출).
바닥 종결·오프셋 링·포함 판정 전부 이 선을 기준으로 한다.

### I-5. 자식 반지름은 부모보다 클 수 없다

R2 ≤ R1, (5심원이면) R3 ≤ R2. 그 범위에서 제약을 못 품으면 **R1 을 5mm 씩 키워 다시 푼다**(최대 600스텝).
"R2 를 R1 보다 크게 허용" 하는 우회를 만들지 마라 — 그건 3심원이 아니다.

### I-6. 여유폭 계산에서 시설한계 하단 3점은 제외한다

시설한계 8점 중 인덱스 `0·1·7` 은 노면 위에 있어 라이닝 바닥선과 같은 선이다. 여유가 0 인 게 당연하므로 제외한다.
(원본 60행에서 여유폭이 44행이나 0 으로 찍힌 것도 같은 이유로 **추정**된다.)

### I-7. 포트 탐지에 `SO_REUSEADDR` 을 켜지 마라

Windows 는 이 옵션이 켜져 있으면 **이미 사용 중인 포트에도 `bind` 가 성공**한다.
실제로 이 때문에 8801 에서 서버가 도는 중에 "8801 사용 가능" 으로 오판했다.
`server.pick_port()` 와 `diagnose.py` 는 절대 켜지 않고, 서버 클래스도 `allow_reuse_address = False` 다.

### I-8. .bat 은 ASCII + CRLF 로만 만든다

한글을 넣으면 cp949 PC 에서 깨져 실행이 실패한다. `90_dist/build_dist.py` 가 생성 시 **비ASCII 문자를 assert 로 막는다**.
RUN.bat / CHECK.bat 을 직접 손으로 고치지 말고 `90_dist/make_bats`(build 스크립트 내 정의)를 고쳐 재생성하라.

### I-9. 추가 설치 없이 돌아야 한다 — **의존성 0**

엔진·뷰어·보고서·JSON·CSV·**DXF 까지 전부 표준 라이브러리만** 쓴다.
DXF 는 `export.py` 가 **R12(AC1009) ASCII 를 직접 쓴다**(엔티티 6종: LINE/ARC/CIRCLE/POLYLINE/POINT/TEXT).
`ezdxf` 를 다시 끌어들이지 마라 — 의존성이 numpy 포함 **92MB** 라 배포가 불가능해진다.
`have_ezdxf()` 는 이제 **게이트에서 되읽기 검증에만** 쓴다(없으면 그 검증만 생략).

배포는 두 벌이다. **경량판**(파이썬 필요, 2.3MB) 과 **파이썬 동봉판**(`runtime\` 포함, 13.5MB).
RUN.bat 이 `%~dp0runtime\python.exe` 를 **1순위**로 찾으므로 폴더만 넣으면 동봉판이 된다.

### I-10. 캔버스 좌표는 DPR 을 곱한다

`app.js` 의 모든 캔버스 그리기는 `devicePixelRatio` 를 곱한 좌표계다. 선 두께·폰트·히트영역 전부.
DPR 을 빼먹으면 고해상도 화면에서만 어긋난다.

## 2. 구조

```
04_engine/section_engine.py   ← 기하·판정·스윕. 단일 진실 원천(SSOT)
04_engine/report.py           ← 검토보고서 HTML 생성
04_engine/export.py           ← DXF / JSON 계약 / CSV
04_engine/gate_check.py       ← 게이트 9종
05_web_viewer/server.py       ← HTTP API + 정적 서빙 (포트 자동 선택)
05_web_viewer/app.js          ← 화면·상호작용. **계산은 하지 않는다**
03_data/inputs_and_results.json ← 발주처 원본 입력·결과 60행 (참조 전용)
90_dist/build_dist.py         ← 배포 빌드 (+ RUN/CHECK.bat 생성)
90_dist/diagnose.py           ← 자가진단 (CHECK.bat 이 호출)
```

### 데이터 흐름

```
[브라우저 입력]
   → POST /api/section  ─┐
   → POST /api/sweep    ─┼→ section_engine.build_section() / sweep()
   → POST /api/report   ─┤       ↑ 여기서만 계산한다
   → POST /api/export   ─┘
   → 응답 JSON(폴리라인·중심·반지름·지표) → app.js 가 **그리기만** 한다
```

★ **엔진은 파이썬 한 곳에만 있다.** JS 에 계산식을 복제하지 마라. 두 벌이 되는 순간 조용히 갈라진다.

### 산정 순서 (build_section)

1. 시설한계 8점 생성 → 시공오차만큼 마이터 오프셋
2. `R1 = ceil5(max 거리)` — 제트팬이 제약이면 `|O1→팬중심| + D/2 + 이격` 도 반영
3. 스프링잉 `±θ/2` 에서 측벽 원호를 내접 → 그 측 제약(시설한계 하부·공동구·검사원통로)을 품는 최소 R2
4. 못 품으면 R1 +5mm 하고 3 반복 (I-5)
5. 노면선과의 교점에서 바닥 종결 → 폴리곤·면적·편평률·여유폭
6. 라이닝/숏크리트/여굴을 **동심 오프셋**해 링과 굴착단면적

## 4. 사용자 질문에 답하는 규칙 ★

이 도구를 **설명**하는 일이라면 아래를 지켜라. 사용자는 이 결과로 설계 판단을 한다.

1. **"원본을 재현했다"고 말하지 마라.** 재현된 건 R1 규칙(56/60)뿐이다. R2/R2′는 신규 정의값이다(I-2).
2. **판정 결과를 확정으로 말하지 마라.** 편평률·여유폭 기준이 잠정이므로,
   "현재 기준값(0.55 / 50mm) 기준으로 OK" 처럼 **기준을 함께** 말한다.
3. **숫자를 지어내지 마라.** 값이 필요하면 `/api/section` · `/api/sweep` 을 실제로 호출하거나
   내보낸 JSON/CSV 를 읽어라. 화면 캡처에서 눈으로 읽은 값은 근거가 약하다.
4. **모르는 것은 모른다고 하라.** 특히: 원본 R2/R2′ 산정식 · 판정 기준 실값 · 부대공 배치 기준 ·
   R1 미일치 4행의 원인 — 이 4가지는 **미확인**이다.
5. **단위를 붙여라.** 내부는 전부 mm 다. 화면 입력만 m 다. 원본 엑셀에는 ㎡ ↔ mm² 오표기가 있었다.
6. 5심원을 "지원한다"고 말할 때는 **"이 배치에서는 불성립해 3심원으로 되돌린다"** 를 같이 말하라.

### 자주 나올 질문과 정확한 답

| 질문 | 정확한 답 |
|---|---|
| 이거 원본 엑셀 계산이랑 같나요? | R1 은 60행 중 56행 일치. R2/R2′는 재현하지 않고 새로 정의했다. 면적·편평률은 같은 대역(75.9~85.1㎡ / 0.539~0.566 vs 원본 76.1~79.5㎡ / 0.544~0.551)에 들어온다. |
| 판정 OK 면 그대로 써도 되나요? | 아니다. 판정 기준이 잠정값이다. 기준을 확정받아 다시 돌려야 한다. |
| Revit 로 바로 넘길 수 있나요? | 애드인은 범위 밖이다. DXF(ARC/LINE 실엔티티)와 JSON 계약(`tn_section/1.0`)까지 준비돼 있어, 그걸 읽는 쪽을 만들면 된다. |
| 왜 5심원이 안 되나요? | 공동구·시설한계 하단이 노면 레벨에서 최대폭을 규정하기 때문이다. 하부를 좁히는 R3 ≤ R2 로는 그 점들을 품을 수 없다. 공동구를 지워도 시설한계 하단 때문에 동일하다. |
| 다른 터널에도 쓸 수 있나요? | 시설한계·공동구·부대공 수치를 바꾸면 된다. 다만 판정 기준과 부대공 배치는 그 현장 기준으로 다시 정해야 한다. |

## 5. 변경 레시피

| 하려는 일 | 절차 |
|---|---|
| **R-1 판정 기준을 확정값으로 바꾼다** | 화면 입력값만 바꾸면 된다(코드 수정 불필요). 기본값을 바꾸려면 `section_engine.judge()` 의 기본 인자와 `index.html` 의 `flat_min`/`margin_min` 초기값. 게이트 재실행. |
| **R-2 부대공 배치 기준을 받았다** | `section_engine.extra_shapes()` 의 배치식만 고친다. `walk_side`·`jet_dx`·`jet_gap_ratio` 파라미터가 이미 있다. G7 재실행. |
| **R-3 새 제약 형상을 추가한다**(예: 배수공) | ① `extra_shapes()` 에 형상 추가 ② `build_section` 의 `conR/conL` 에 점을 넣는다 ③ `app.js` 그리기 ④ **게이트에 포함 검사를 추가**한다. 검사를 안 만들면 추가한 게 아니다. |
| **R-4 목적함수를 바꾼다**(예: 굴착면적 최소) | 정렬 기준은 `app.js` 의 `fillTable()`/`buildThumbs()` 와 `report.build()` 의 `sorted(...)`. 엔진은 `exc_m2` 를 이미 준다. |
| **R-5 스윕 축을 추가한다** | `sweep()` 의 4중 루프 + `DEFAULT_SWEEP` + `index.html` 스윕표 + `app.js` `sweepDef()`. 조합 수가 곱으로 늘어난다는 점에 주의. |
| **R-6 내보내기 형식을 추가한다** | `export.py` 에 `to_xxx()` 추가 → `server.py` `/api/export` 분기 → `app.js` 버튼. G9 에 검사 추가. |
| **R-7 화면만 고쳤다** | 캐시버스트 버전(`?v=YYMMDDx`)을 **반드시** 올리고 사용자에게 Ctrl+F5 를 안내한다. |
| **R-8 배포판을 다시 만든다** | `python 90_dist/build_dist.py`. 새 파일을 추가했으면 `FILES` 목록에 넣어야 한다 — **안 넣으면 조용히 빠진다.** |

### 성능 규칙

- 스윕 900조합이 0.2초다. `build_section` 안에 O(n²) 을 넣지 마라 — 조합마다 도는 함수다.
- `app.js` 는 `refresh()` 를 연타해도 되게 `pending` 플래그로 직렬화돼 있다. 유지하라.

## 6. 보고 규율

- **주장 = 증거 등급 일치.** "코드에 넣었다" ≠ "동작한다" ≠ "원본과 맞다".
- 화면 관련 주장은 **캡처에서 해당 요소를 지목할 수 있을 때만** 한다.
- 게이트 PASS 는 "게이트가 검사한 범위에서" 정상이라는 뜻이다. 게이트가 안 보는 걸 PASS 로 말하지 마라.
- **미확인은 미확인으로 쓴다.** 사용자가 검증 책임을 지게 만드는 보고는 기만이다.
