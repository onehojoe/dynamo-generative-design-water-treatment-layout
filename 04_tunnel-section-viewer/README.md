# 04 · NATM 터널 내공단면 산정 뷰어 / NATM Tunnel Inner-Section Viewer

**설계 조건을 넣으면 NATM 도로터널의 3심원 내공단면을 그 자리에서 그려 보이고,
조건을 스윕해 만든 대안을 비교·판정해 하나를 고르게 해 주는 브라우저 도구입니다.**
Revit·Dynamo 없이 돌아갑니다. 고른 안은 DXF·JSON·CSV·검토보고서로 바로 나옵니다.

> 03 이 «부지 안 시설 배치», 05 가 «부지를 가로지르는 도로» 라면,
> 04 는 «그 도로가 산을 지날 때의 **단면 그 자체**» 입니다.
> 앞의 것들이 *배치*를 다룬다면 여기서는 **단면 형상이 설계 기준에서 어떻게 결정되는가**를 다룹니다.

---

## 실행

**`RUN.bat` 더블클릭.** 브라우저가 자동으로 열립니다. 창을 닫으면 종료됩니다.

- 추가 설치 없음. **파이썬 3.8 이상**만 있으면 됩니다(없으면 RUN.bat 이 안내).
- 8801 포트가 쓰이고 있으면 **8802, 8803… 으로 자동으로 옮겨** 뜹니다.
- 안 되면 **`CHECK.bat`** → 화면과 `CHECK_RESULT.txt` 에 진단이 남습니다.

압축본이 필요하면 `TN_SECTION_VIEWER_v1.0_260825.zip` 을 그대로 전달하면 됩니다(내용 동일).

## 기능

- **실시간 작도** — 결정변수 4축(도로중심거리·편경사·중심높이 EL1·중심각 θ)을 움직이면 단면이 즉시 다시 그려집니다.
  R1 파랑 / R2 노랑 / R2′ 분홍, 중심점·스프링잉·치수·공동구·부대공·라이닝·숏크리트·굴착선.
- **스윕과 대안 탐색** — 900조합을 0.2초에 계산해 파레토 산점도(면적 ↔ 편평률)와 정렬표로 보여 줍니다.
  표의 행을 클릭하면 그 조건이 즉시 단면에 반영됩니다(역추적). 상위 12안은 형상 썸네일로 나란히 비교합니다.
- **판정** — 편평률·시설한계 여유폭·포함 여부. **기준값은 화면에서 바꿀 수 있습니다**(하드코딩 아님).
- **부대공** — 검사원통로·제트팬을 `표시` / `제약 반영` 으로 따로 켭니다.
- **산출** — DXF(실제 ARC/LINE 엔티티·레이어 9종·mm) · JSON 계약 · CSV · 검토보고서(HTML→인쇄 시 PDF).

## 검증

```
python 04_engine/gate_check.py
```

게이트 9종을 스윕 900조합 전수로 검사합니다(시설한계 재현 · 원본 대조 · 포함 · 폴리곤 건전성 ·
치수 정합 · 부대공 제약 · 층 단조성 · 내보내기 무결성). `CHECK.bat` 은 그중 엔진 계산을 기준값과 대조합니다.

## ⚠ 알고 써야 할 것 — 근거의 등급

이 도구는 **무엇을 보장하고 무엇을 보장하지 않는지**를 구분해서 말합니다. 검토보고서에도 같은 내용이 자동으로 들어갑니다.

| 항목 | 등급 |
|---|---|
| 시설한계 8점 작도 | **원본 이식** — 10800×4800 · 51.040㎡ 검산 통과 |
| **R1** = 시설한계+시공오차를 감싸는 최소 반지름(5mm 격자) | **원본 결과 60행 중 56행과 정확히 일치**. 미일치 4행은 원본이 9~14mm 크게 잡았고 **원인 미확인** |
| **R2 / R2′** | **새로 정의한 값**. 원본 산정식이 제공 자료에 없어 **재현하지 않았습니다**. 원본 60행은 뷰어의 `[원본 60행]` 탭에 **참조용으로만** 병기 |
| 판정 기준 (편평률 0.55 · 여유폭 50mm) | **추정 / 잠정** — 확정 기준이 아닙니다 |
| 부대공 배치 | **가정** — 배치 기준이 자료에 없습니다 |
| 5심원 (R3/R3′) | 구현돼 있으나 공동구·시설한계 하단이 노면 레벨 최대폭을 규정하는 배치에서는 성립하지 않아 **3심원으로 자동 복귀**하고 사유를 표시 |

**범위** — 내공선부터 굴착선까지. 지보패턴·록볼트·배수공·Revit 애드인은 들어 있지 않습니다.

**출처** — 한국종합기술 기술연구소 제공 자료(발표자료·Dynamo 그래프·입력 엑셀)를 근거로 재구성했습니다.
`03_data/inputs_and_results.json` 의 프로젝트 정보와 결과 60행은 그 원본에서 온 값입니다.
