1. 이 도구는 무엇인가

설계 조건을 넣으면 NATM 도로터널의 3심원 내공단면을 그 자리에서 그려 보이고, 조건을 바꿔가며 만든 대안들을 비교·판정해 하나를 고르게 해 주는 도구입니다. 고른 안은 도면(DXF)·계약(JSON)·표(CSV)·검토보고서로 바로 뽑힙니다.

→
결정변수 4축중심거리·편경사·EL1·중심각
→

범위 — 내공선부터 굴착선까지입니다. 지보패턴·록볼트·배수공·Revit 애드인은 들어 있지 않습니다.

2. 실행

  1. RUN.bat 더블클릭. 브라우저가 자동으로 열립니다. 창을 닫으면 종료됩니다.
  2. 파이썬 동봉판(폴더 안에 runtime\ 이 있는 것)이면 설치할 것이 전혀 없습니다. 관리자 권한도 필요 없고, PC 에 이미 깔린 파이썬과 충돌하지도 않습니다.
    경량판이면 파이썬 3.8 이상이 필요합니다. 없으면 RUN.bat 이 다운로드 주소를 알려 줍니다 (설치 시 Add python.exe to PATH 체크).
  3. 8801 번 포트를 다른 프로그램이 쓰고 있으면 8802, 8803… 으로 자동으로 옮겨 뜹니다. 창에 실제 주소가 찍힙니다.
안 되면 CHECK.bat 더블클릭. 파이썬·필수파일·엔진 계산·포트·쓰기권한을 검사해 화면과 CHECK_RESULT.txt 에 남깁니다. [FAIL] 줄이 있으면 그 파일을 그대로 보내 주시면 됩니다.

3. 화면 구성

입력 패널 자세히

4. 5분 따라하기

  1. 시설한계를 확인한다. 좌측 시설한계 칸의 차로폭·길어깨·통과높이 H·헌치 a/b 를 현장 값으로 맞춥니다. 단위는 m 입니다. 바꾸는 즉시 가운데 단면이 다시 그려집니다.
  2. 공동구를 넣는다. 좌·우 폭/높이. 이 사각형이 측벽 반지름을 결정하는 경우가 많습니다.
  3. 결정변수 4축을 슬라이더로 훑어본다. 도로 중심거리 · 편경사 · 중심높이 EL1 · 중심각 θ 를 움직이면 상단 카드(R1 / 면적 / 편평률 / 여유)가 실시간으로 바뀝니다. 어느 변수가 무엇을 키우는지 감을 잡는 단계입니다.
  4. 스윕 범위를 정하고 [스윕 실행]. 기본값은 900조합이고 1초 안에 끝납니다. 오른쪽에 파레토 산점도와 대안 표가 채워집니다.
  5. 대안을 고른다. 표의 행을 클릭하면 그 조건이 즉시 왼쪽 단면에 반영됩니다(역추적). 형상을 나란히 보고 싶으면 [대안 형상 비교] 탭에서 상위 12안을 한눈에 봅니다.
  6. 뽑는다. 상단 [검토보고서] 로 보고서를, [DXF] [JSON] [CSV] 로 산출물을 내려받습니다.

7. 대안 탐색

파레토 산점도 읽는 법

  • 가로축 = 내공단면적. 왼쪽일수록 굴착이 적어 경제적입니다.
  • 세로축 = 편평률. 위쪽일수록 형상이 안정적입니다.
  • 따라서 왼쪽 위가 좋은 영역입니다. 초록(판정 OK) 중 왼쪽 위 경계선에 있는 점들이 서로 우열을 가릴 수 없는 후보입니다.
  • 노랑 = 지금 화면에 그려진 안, 분홍 = 판정 OK 중 최소면적 안.
표의 행을 클릭하면 그 조건이 슬라이더까지 반영돼 왼쪽 단면이 바뀝니다. 숫자로 고른 뒤 형상으로 확인하는 순서가 실수를 줄입니다.

10. ★ 알고 써야 할 한계

이 도구가 보장하는 것과 보장하지 않는 것은 다릅니다. 보고서에도 같은 내용이 자동으로 들어갑니다.
  • R1 은 근거가 강합니다. "시설한계+시공오차를 감싸는 최소 반지름(5mm 격자)" 규칙이 발주처 원본 결과 60행 중 56행과 정확히 일치합니다. 나머지 4행은 원본이 9~14mm 크게 잡았고 원인은 확인되지 않았습니다.
  • R2 / R2′ 는 새로 정의한 값입니다. 원본의 산정식이 제공 자료에 없어 재현하지 않았습니다. 스프링잉에서 접선 연속으로 잇고 그 측 제약을 품는 최소 반지름으로 구성한, 표준 작도에 따른 값입니다. 원본 60행은 뷰어의 [원본 60행] 탭에 참조용으로만 병기해 두었습니다.
  • 판정 기준(편평률·여유폭)은 잠정값입니다(§6 참조).
  • 부대공 배치는 가정입니다. 기준을 받으면 위치 파라미터를 바꾸면 됩니다.
  • 5심원(R3/R3′)은 구현돼 있으나, 공동구·시설한계 하단이 노면 레벨에서 최대폭을 규정하는 배치에서는 성립하지 않아 3심원으로 자동 복귀하고 사유를 표시합니다.
  • 지보패턴·록볼트·배수공은 미반영입니다.
