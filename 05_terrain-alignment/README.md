# 05 · 지형·선형 GD 워크벤치 / Terrain & Alignment GD Workbench

등고선 지형을 만들고, 그 위에서 도로의 **평면 + 종단** 선형을 Generative Design 으로 찾는다.
**`RUN.bat` 더블클릭이 전부** — 서버·설치·인터넷·파이썬 전부 불필요.

Build terrain (contours), then search road **horizontal + vertical** alignment with a GA.
Double-click `RUN.bat`. No server, no install, no Python.

---

## 03 과 무엇이 다른가

| | `03_web-workbench` | **`05_terrain-alignment`** |
|---|---|---|
| 문제 | 부지 안에 **시설 박스 배치** | 부지를 가로지르는 **도로 선형** |
| 차원 | 2D 평면 | **평면 + 종단(3D)** |
| 지형 | 없음 | **등고선 지형이 정본** |
| 목적 | 연결 길이·비용 | 토공(절·성토)·경사·구조물 |
| 제약 | 겹침 금지 | **종단경사 ±8%**(입력) · 종단곡선 K |

같은 «변수를 훑어 대안을 만들고 골라낸다» 는 구조이지만, 지형이 들어오면서
제약이 기하에서 **설계기준**으로 옮겨간다. 그 차이를 보는 것이 이 모듈의 요점이다.

---

## 먼저 알아 둘 것 (정직 고지)

1. **부지 데이터는 합성 샘플이다.** `tools/make_sample_site.py` 로 만든 것이며
   특정 시설을 나타내지 않는다. 실제 프로젝트 데이터가 아니다.
2. **지형도 전량 합성이다.** 표고를 프로그램이 만들어 낸다.
3. **설계기준 수치 12개 중 11개가 법령 원문 대조 전이다.**
   화면의 «수치 n/12 검증» 배지가 그것이다. **그대로 설계 근거로 쓰면 안 된다.**
   대조 절차는 `data/standards_registry.json` 안에 적혀 있다.
4. **터널·교량 판정은 높이 임계값**이다. 실무 결정은 토공 대 구조물의 경제성 비교다.
5. Dynamo 원본 그래프와의 **실행값 대조는 하지 않았다**(사양 이식까지만 확인).

## 30초 사용법

1. `RUN.bat` 더블클릭
2. 우측 **지형 변수** 에서 산·하천을 바꾸고 `[지형 재생성]`
3. **종단 설계** 에서 최대 종단경사(기본 ±8%)·도로폭 등을 정한다
4. **최적화 (GA)** 에서 `[최적화 실행]` → `[대안 갤러리]` 에서 고른다

자세한 것은 `README.md`(사용 설명서). 한 장으로 읽으려면 `docs/설명자료.html`.
**AI 에게 맡길 거면 `AI_GUIDE.md`** 를 먼저 읽히면 된다 — 구조·계약·이미 밟은 함정이 적혀 있다.

## 실제 지형을 넣으려면

```
python tools/import_terrain.py <파일>   # .asc .xyz .csv .xml(LandXML) .dxf(등고선)
python tools/pack_data.py
```
이 두 가지에만 파이썬이 필요하다. 좌표계 변환은 하지 않는다 — 미리 맞춰서 넣어야 한다.
