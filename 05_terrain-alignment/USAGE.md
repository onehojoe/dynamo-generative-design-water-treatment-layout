# 지형·선형 GD 워크벤치 — 사용 설명서

지형(등고선)을 만들고, 그 위에서 도로의 **평면 + 종단** 선형을 Generative Design 으로
찾는 도구다. 브라우저만 있으면 된다.

> **한 줄 요약** — `RUN.bat` 더블클릭 → 우측에서 값 바꾸기 → `[최적화 실행]` → 대안 고르기.

---

## 1. 실행

**`RUN.bat` 을 더블클릭한다.** 끝이다.

![실행 직후 화면 — 왼쪽 위 평면, 아래 종단면·횡단면, 오른쪽 조작 패널](img/01_overview.png)

- 파이썬·서버·인터넷 **전부 불필요**. 데이터가 `data\*.js` 에 구워져 있어 파일에서 바로 열린다.
- 잘 안 되면 `web\index.html` 을 브라우저로 직접 열어도 똑같다.
- 화면이 옛날 것처럼 보이면 **Ctrl+F5**(강력 새로고침).
- 제대로 받았는지 확인하려면 **`TEST.bat`** — 파일 8종 검사. (검사기만 파이썬을 쓴다. 없으면 파일 존재만 본다.)

권장 브라우저는 Chrome 또는 Edge. `RUN.bat` 이 둘을 먼저 찾고, 없으면 기본 프로그램으로 연다.

## 3. 순서대로 해 보기

### ① 지형을 정한다
`지형 변수` 에서 슬라이더를 움직이고 **`[지형 재생성]`** 을 누른다.

![지형·지형 변수 패널 — 산 개수·높이·반경, 하천 깊이·폭, 잡음, 시드](img/03_terrain_panel.png)

| 변수 | 무엇이 바뀌나 |
|---|---|
| 기준표고 | 전체 표고를 위아래로 |
| 전체경사 방향·율 | 대지 전체가 어느 쪽으로 기우는가 |
| **산 개수 / 높이 배율 / 반경 배율** | 산이 몇 개, 얼마나 높고 넓은가 |
| **하천 깊이 / 폭** | 골짜기가 얼마나 깊고 넓은가 |
| 잡음 진폭 / 옥타브 | 지형의 잔주름 |
| 지형 시드 · `[주사위]` | 같은 설정에서 다른 지형 |

같은 부지에서 변수만 바꾼 결과다. 왼쪽이 기본(시드 7 · 산 3개), 오른쪽이 산 5개·높이 1.6배·하천 깊이 40 m.

![기본 지형 — 시드 7 · 산 3개](img/04_terrain_seed7.png)

![산 5개 · 높이 1.6배 · 하천 40 m 로 재생성 — 선형이 지나는 자리도 함께 달라진다](img/05_terrain_alt.png)

`[원본 복귀]` 로 처음 지형으로 되돌린다.
슬라이더를 움직이는 즉시 바뀌지 않고 **버튼을 눌러야** 다시 계산한다(격자가 12만 칸이라 무겁다).

### ② 도로 조건을 넣는다
`종단 설계` 에서:

| 입력 | 기본 | 뜻 |
|---|---|---|
| 설계속도 V | 60 | 60·80·100 중 고르면 아래 값들이 따라 바뀐다 |
| **최대 종단경사 ±%** | 8 | 이걸 넘으면 **실격**. 직접 숫자를 넣는다 |
| 최소 종단경사 % | 0.3 | 배수를 위한 하한 |
| 종단곡선 K 볼록/오목 | 11 / 15 | 종단곡선이 이보다 완만해야 한다 |
| 도로폭 B m | 20 | 토공 계산의 노면 폭 |
| 절토·성토 비탈면 1:m | 1.2 / 1.5 | 비탈면 기울기 |
| 편경사 % | 2 | 횡단의 좌우 기울기 |
| 측점 간격 m | 20 | 종단·토공을 계산하는 간격 |
| 종단도 GD로 탐색 | 켬 | 끄면 계획고를 자동으로만 정한다 |
| 계획고 탐색폭 ±m | 25 | GD 가 계획고를 얼마나 흔들어 볼지 |

`구조물 판정` 에서 터널·교량으로 넘어가는 높이와 최소연장을 정한다.

![구조물 판정 패널과 설계기준 등록부 — 판정 결과(토공·터널·교량 연장)와 미검증 수치 목록이 같이 나온다](img/08_struct_panel.png)

### ③ 대안을 찾는다
`최적화 (GA)` 에서 Population·Generation 을 정하고 **`[최적화 실행]`**.

- **토공 벌점(점/백만 m³)** — 올릴수록 토공이 큰 대안이 밀린다. 0 이면 기존 v7 총점 그대로.
- **대지 이탈 벌점(점/km)** — 선형이 대지 밖으로 나가는 것을 막는다. 0 으로 두면
  GD 가 대지 밖으로 빠져 토공 계산을 피해 간다(실제로 겪은 일이다).

![최적화 후 — 왼쪽 갤러리에서 대안을 고르면 평면·종단·횡단이 함께 바뀐다](img/09_gallery.png)

끝나면 `[대안 갤러리]` 에서 후보를 눈으로 고른다. 카드를 누르면 평면·종단·횡단이 그 대안으로 바뀐다.

## 4. 숫자를 어떻게 읽나

**종단면 머리줄**
`연장 · 최대경사 · 절토 · 성토 · 불균형 · 터널 · 교량 · 구조물 n m 토공 제외 · 기준 만족/위반`

- **불균형** = |절토 − 성토|. 클수록 흙을 밖에서 들여오거나 밖으로 버려야 한다.
- **구조물 … 토공 제외** = 터널·교량 구간이라 절성토를 계산하지 않은 연장.
- **위반** 이 뜨면 종단경사나 종단곡선 K 가 기준을 벗어난 것이다. 그 구간은 종단에서 **빨강**으로 나온다.

**토공 계산 방식** — `토공을 단면 스윕으로` 가 켜져 있으면 선형 법선 방향으로 지형을 잘라
**실제 지반 횡단형상**과 계획면 사이 면적을 잰다(편측 절토·편측 성토가 잡힌다).
끄면 근사식 `A = |h|·B + m·h²` 를 쓴다. 둘의 차이를 비교해 볼 수 있다.

## 5. 반드시 알고 쓸 것 (정직 고지)

1. **지형은 전량 합성이다.** 원본 데이터에 표고(Z)가 없어서 프로그램이 만들어 낸 것이다.
   **실제 지형과 무관하다.** 실지형을 쓰려면 §6 을 보라.
2. **설계기준 수치 12개 중 11개가 법령 원문 대조 전이다.** 화면의 `수치 n/12 검증` 배지가 그것이다.
   최대 종단경사·종단곡선 K·비탈면 기울기는 **관행값**이며 그대로 설계에 쓰면 안 된다.
3. **터널·교량 판정은 높이 임계값**으로 한다. 실무 결정은 토공 대 구조물의 경제성 비교다.
   여기 판정은 «어디쯤 구조물이 필요하겠다» 를 빠르게 보는 용도다.
4. **대지는 데이터 범위 + 여유 150 m 의 사각형**이다. 실제 사업 부지 경계가 아니다.
5. 원본 `도로` 레이어가 도로인지 수계인지 **확인되지 않았다**.

## 6. 실제 지형을 넣으려면 (선택)

`import_terrain.py` 로 외부 지형을 `terrain.json` 으로 바꾼 뒤 `pack_data.py` 로 다시 굽는다.
이 두 가지만 파이썬이 필요하다.

```
python tools/import_terrain.py <파일> --cell 20 --interval 5
python tools/pack_data.py
```
합성 지형을 다시 만들려면 `python toolsuild_terrain.py` (지형 변수는 파일 상단 `PARAMS`).

| 형식 | 확장자 | 비고 |
|---|---|---|
| ESRI ASCII Grid | `.asc` `.txt` | 왕복 시험 완료(값 완전 일치) |
| 점군 | `.xyz` `.csv` | `x y z` 또는 `x,y,z`. 왕복 시험 완료 |
| LandXML 표면 | `.xml` | 구현됨, **표본 미시험** |
| DXF 등고선 | `.dxf` | 구현됨, **표본 미시험**. `ezdxf` 필요 |

★ **좌표계 변환은 하지 않는다.** 파일 좌표가 대지와 같은 계라고 가정한다.
다르면 미리 변환해서 넣어야 한다 — 프로그램이 추측하지 않는다.
대지 범위 밖 점 비율을 실행 중에 알려 주므로, 0% 에 가까우면 좌표계를 의심할 것.

## 7. 잘 안 될 때

| 증상 | 원인·조치 |
|---|---|
| 빈 화면 / 그림이 없다 | 압축을 폴더째 풀지 않았다. `web`·`data` 폴더가 나란히 있어야 한다. `TEST.bat` 실행 |
| 소스 코드가 그냥 보인다 | `.html` 이 편집기에 연결돼 있다. Chrome/Edge 로 직접 열 것 |
| 옛날 화면이 나온다 | **Ctrl+F5** |
| 지형 재생성이 느리다 | 정상. 격자 12만 칸을 다시 계산한다(수백 ms~수 초) |
| 최적화가 멈춘 것 같다 | Population×Generation 만큼 평가한다. 먼저 Pop 20 / Gen 15 로 감을 잡을 것 |
| 종단이 이상하다 | `측점 간격` 을 줄이면(예: 10 m) 지형을 더 촘촘히 따라간다 |
| 대안이 다 실격이다 | `최대 종단경사` 가 너무 빡빡하거나 지형 기복이 너무 크다. 산 높이 배율을 낮춰 볼 것 |

```

README.md               이 문서 — 사용 설명서
AI_GUIDE.md             AI 에게 이 도구를 설명하는 문서
CHANGELOG.md            판올림 기록
web/
  index.html            화면
  js/  terrain.js       지형 적재·샘플·등고선 경로
       terrain_gen.js   지형 생성 + marching squares
       alignment.js     평면 선형(직선·원곡선·클로소이드)
       profile.js       측점·계획고·종단곡선·경사검토·터널교량·토공
       section.js       횡단면 스윕

       app.js           화면·상호작용
data/
  site.js/.json      대지·도로·장애물
  terrain.js/.json      지형 격자 + 등고선
  _aux.js               설계기준 등록부 등
tools/
  selfcheck.py          자가검사 본체
  pack_data.py          JSON → JS 굽기 (data/*.json → data/*.js)
  build_terrain.py      합성 지형 생성기
  import_terrain.py     외부 지형 읽기 (ASC/XYZ/LandXML/DXF)
```
