## 1. 수처리 계통 검토 — 배치 규칙을 어디서 끌어올 것인가

### 1-1. 공정 계열 판독

박스 라벨과 dyn·PPT 연결쌍을 대조하면 이 정수장은 **후처리형 고도정수처리** 계열이다.

```
[원수] → [1]착수정 → [2]혼화지 → [3]침전지 → [4]급속여과지 → [5]오존접촉조 → [6]활성탄흡착지 → [7]정수지 → [송수, 부지 외]
```

- dyn 연결쌍의 `3-4, 4-5, 5-6, 6-7` 이 이 순서를 지지한다(침전→여과→오존→BAC→정수지).
- PPT Rule 의 `5-6-7` 도 같다. 두 자료가 본류에서는 일치한다.
- ※ "침전→오존→BAC→여과"(중간오존형)도 실무에 존재하나, 두 자료 모두 여과가 오존 앞이다.
  **본류 순서는 Cho 확인 대상**으로 남긴다(§7 결정 A).

### 1-2. 부대 계통 — 두 자료 어디에도 완전히 안 들어있는 부분

| 계통 | 실제 흐름 | dyn | PPT |
|---|---|---|---|
| 역세척 | [7]정수지 → **[8]역세척펌프장** → [4]여과지 | ❌ 없음 | ❌ 없음 |
| 역세배출수 | [4]여과지 → [9]배출수지 | ❌ | ✅ `4-9` |

각 규칙을 "실무 의미 × 지금 데이터로 계산 가능한가"로 평가했다.

| R3 | **자연유하 단조성** | 정수장 본류는 무동력 중력흐름이 원칙(착수정 최고 → 정수지 최저). 배치가 되돌아가면 관로가 길어지고 수두손실이 커진다. 표고가 없어도 **본류 주축에 대한 역행 링크**로 대리 측정 가능 | 주축 투영 | **C5 제약으로 채택** |

**보류(데이터 없음):** 표고·절성토 물량, 도로망 실연장, 수리계산 낙차, 지하매설 간섭.
원본 dyn 주석의 *"추후 지형·이격 추가해야함" / "추후 도로 및 이동 관련 추가해야함"* 이 정확히 이 영역이다 → **2단계**.

### 1-5. ★설계 원칙 — 규칙이 늘어도 목표는 늘리지 않는다

규칙 9종을 전부 목표로 만들면 안 된다. 목표가 5개를 넘으면 거의 모든 해가 비지배가 되어 파레토가 붕괴한다.
**규칙을 세 갈래로 나눠 담는다:**

```
규칙  ──┬─→ 목표(objective)  4개까지.  서로 상충하는 것만.
        ├─→ 제약(constraint) 만족/불만족이 명확한 것. 탐색공간을 줄여준다.
        └─→ 가중치(weight)   같은 목표 안에서 경중을 표현. 축을 늘리지 않는다.
```

## 3. 입력 — UV 전환

### 3-1. 원리
dyn의 후보점은 이미 바닥면 파라미터 `0..1..0.02`(51×51 UV)에서 나온다.
시드는 그 위를 **섞는** 우회로였다. **UV 전환은 새 방식이 아니라 그래프 본래 좌표계로의 복귀다.**

### 3-2. 무효해 처리 — 세 갈래 중 B 채택

| 안 | 방식 | 판정 |
|---|---|---|
| A 페널티 | 겹침 허용·겹침면적 가산 | 파레토가 무효해로 오염 |
| **B 최근접 수복** | UV 목표점에서 **가장 가까운 유효점**으로 밀어넣음 | **채택.** 연속성 유지 |
| C 하드 리젝 | 무효면 폐기 | 세대 대부분 낭비 |

**B는 엔진을 거의 안 고친다.** `runPlacement` 의 정렬 기준 한 줄 교체다:
```js
// 현행: const tries = shuffled(avail, seeds[k] + k*101);
// v0.4: const tries = avail.slice().sort((p,q) => d2(p,target) - d2(q,target));
//       target = [minX + u*(maxX-minX), minY + v*(maxY-minY)]
```
겹침검사·경계검사·후보점 정리는 **전부 재사용**된다.
(구현은 정렬 대신 격자 나선 탐색을 썼다 — 결과는 같고 훨씬 싸다. 평가 1회 ≈4.3ms 실측.)

### ★3-2-1. 정정 — "수복이면 항상 유효해"는 틀렸다 (2026-08-25 구현 중 실검출)
고정 순서 그리디라 앞의 10개가 자리를 차지하면 **마지막 큰 시설이 앉을 자리가 0인 경우가 실제로 있다** —
무작위 500건 중 10건, 전부 **[13] 관리동(60.6×40.5m)**. 전 격자 전수 스캔으로 '가능한 자리 0'임을
확인했으므로 엔진 결함이 아니라 기하학적 불가능이며, 미배치 → C1 실격으로 처리한다.
게이트도 "전부 성공"이 아니라 **"미배치는 전수 스캔 가능자리 0일 때만 발생"** 을 검사하도록 바꿨다.

## 4. 실행 계획 — 5단계

### P2. 연결망 정본화 〔결정 3〕  ✅ 완료 (본류 순서·오기 판정은 Cho 확인 대기)

### P3. 가중치·단가 〔결정 4〕  ✅ 완료 (정규화 지수로. 실단가 미확보)
